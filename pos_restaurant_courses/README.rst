This module backports the Courses functionality from Odoo 19.0 pos_restaurant module to Odoo 18.0.

It adds the ability to organize orders into courses in the Point of Sale restaurant module.

**Features:**

* Create and manage multiple courses within an order
* Assign order lines to specific courses
* Fire courses to send them to the kitchen
* Visual course display in the order summary
* Course selection and management in the POS interface

This allows restaurant staff to better manage the order flow and ensure that
dishes are prepared in the correct sequence (e.g., appetizers, main courses, desserts).

Usage
=====

1. Install the module from the Apps menu
2. Make sure pos_restaurant module is installed
3. Open Point of Sale
4. Create an order for a table
5. Add products to the order
6. Products will be organized by courses
7. Select a course and click "Fire Course" to send it to the kitchen
